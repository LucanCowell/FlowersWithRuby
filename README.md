# FlowersWithRuby
This is a website for the local flower business, Flowers With Ruby.

This website aims to ensure that potential customers are able to easily access the store and information from Flowers With Ruby.

This website will consist of two main pages.

- A home page:
  That includes the information about the
  business, such as about the owner, the
  location, etc

- A store page:
  That includes the "how to use" for the store
  due to its unique nature of not charging the user
  and instead sending an email to the owner for discussion 
  and confirmation
