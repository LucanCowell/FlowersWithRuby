# FlowersWithRuby
This is a mock-up website for the local flower business, Flowers With Ruby.

This website aims to ensure that potential customers are able to easily access the store and information from Flowers With Ruby.

This website will consist of two main pages.

- A home page:
  That includes the information about the
  business, such as about the owner, the
  location, etc

- A Store Page:
  That includes the store and how to use the store
  based off the unique nature of the store sending an 
  email to the owner, for a follow up conversation to
  occur.

  - The "How to Use" guide:
    This guide will show as a pop-up modal that activates when first 
    accessing the store but will also be able to be manually activated
    at the press of a button.
